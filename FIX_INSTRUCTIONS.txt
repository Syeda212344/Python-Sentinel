PYTHON SENTINEL - LOGIN / LOGOUT FIX

1. BACK UP your existing Python_Sentinel_Django/data/sentinel.db first.
2. This ZIP intentionally does NOT contain a database, .env, or .git directory.
3. Close the running Django server (Ctrl+C).
4. Extract the ZIP. Copy its Python_Sentinel_Django project files into your
   existing Python_Sentinel_Django folder, allowing file replacements.
   DO NOT DELETE your existing data/sentinel.db.
5. In VS Code terminal, change to your existing Python_Sentinel_Django folder.
6. Run:
       py manage.py check
       py manage.py migrate
       py manage.py runserver 127.0.0.1:8000 --noreload
7. Open http://127.0.0.1:8000/accounts/login/ and sign in.
8. Visit http://127.0.0.1:8000/ and use the Logout button at top right.
